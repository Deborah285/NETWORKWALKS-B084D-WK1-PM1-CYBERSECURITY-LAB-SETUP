# NETWORKWALKS-B084D-WK1-PM1-CYBERSECURITY-LAB-SETUP
Isolated virtual lab built with VirtualBox and Kali Linux for cybersecurity testing and pen testing practice

# Project Overview
This project focuses on setting up a virtual cybersecurity and pen testing lab using VirtualBox and Kali Linux

The purpose of this lab is to create a controlled environment where cybersecurity tools, network scanning, reconnaissance, vulnerability assessment and other security testing activities can be securely carried out.

The lab is configured on a private virtual network so that additional machines can later be added and used as targets for security testing

# Objectives
The main objectives of this project are to :
Install/import Kali Linux as a virtual machine
Create a private NAT network for the cybersecurity lab
Configure network connectivity for Kali Linux
Assign a consistent IP address to the Kali VM 
Verify network connectivity and DNS resolution
Take a clean snapshot for recovery
Document the setup process

# Lab Environment
Host OS - Windows 10

Hypervisor - VirtualBox 7.2

Security OS - Kali Linux 2026.2

Network Address - 10.0.0.0/24

Kali IP - 10.0.0.2/24

Default Gateway - 10.0.0.1

DNS Server - 8.8.8.8

# Disclaimer
All activities are performed in my own virtual lab for educational purposes. Testing will be limited to systems I own or have explicit permission to assess.
